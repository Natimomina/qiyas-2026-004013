# Models

Put the model files from the supplied `models.zip` into this folder.

Expected files:

- `rating_model.pkl`
- `revenue_model.pkl`
- `success_classifier.pkl`
- `movie_tfidf_vectorizer.pkl`
- `movie_tfidf_matrix.npz`
- `movie_title_index.pkl`
- `movie_recommendation_data.csv`

The Flask app loads these artifacts at startup.
