# Trained Models

This directory is intended to contain trained machine learning models generated by the notebook.

Expected files include:

```text
models/
├── mfcc_gender_model.joblib
├── mel_gender_model.keras
└── metadata.joblib
```

### MFCC model

The Random Forest model is saved using Joblib:

```text
mfcc_gender_model.joblib
```

### Mel spectrogram model

The CNN model is saved using the Keras format:

```text
mel_gender_model.keras
```

The trained model files may be excluded from GitHub if they are large.

They can be regenerated by running the training sections of the notebook.
